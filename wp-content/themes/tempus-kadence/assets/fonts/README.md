# Brand web fonts (required before launch)

Drop the CLIENT-SUPPLIED licensed font files here, matching the filenames
referenced by the `@font-face` rules in `../css/tokens.css`:

- `maharlika-regular.woff2`
- `proximanova-cond-regular.woff2`
- `proximanova-cond-bold.woff2`
- `cormorantgaramond-variable.woff2`
- `cormorantgaramond-italic.woff2`

Or update the `src` paths in tokens.css if the filenames differ. Until then
the stacks fall back to Cormorant Garamond → Georgia and Roboto Condensed →
Arial Narrow.
